# Liquid Glass — клиентский мод для Minecraft 26.3 (Fabric)

Чисто визуальный клиентский мод: заменяет главное меню на меню в стиле «liquid glass» —
анимированный фон-аврора, стеклянный заголовок и матовая карточка с кнопками
(Singleplayer / Multiplayer / Options / Quit). Открывает те же ванильные экраны, что и обычное меню.

## Эффекты (кнопка Visuals в главном меню)

Настройки применяются сразу и сохраняются в `config/liquid-glass.properties`.

- **Jump Circles** — расширяющееся кольцо частиц у ног при прыжке. Это обычные частицы игры,
  не настоящий 3D-круг как в читерских клиентах. Стиль (цвет) переключается кнопкой Circle Style.
- **Weather (ambience)** — Off / Clear / Rain / Storm. Меняет только то, как погода выглядит
  у вас на экране; настоящая погода на сервере не меняется.
  Время суток намеренно не трогается: ночь, которая выглядит как день, на многих серверах считается
  преимуществом (как fullbright).
- **No Swing** — скрывает анимацию взмаха вашей руки. Удары работают как обычно, сервер видит обычную игру.

Эффекты подключены миксинами с `require = 0`: если в Minecraft 26.3 какой-то метод называется
иначе, эффект просто не заработает (в `logs/latest.log` будет запись), но игра не упадёт.

**Легитимность.** Мод только рисует интерфейс на клиенте. Он не меняет геймплей, не трогает
мир, сущностей, пакеты и ввод в игре, ничего не отправляет на сервер и не зависит от Fabric API.
Для античитов и правил серверов такой мод невидим — это тот же класс, что и моды на темы меню.

> ⚠️ Проект написан под API 26.3 по документации Fabric, но **не был скомпилирован и запущен**
> при создании (в среде не было доступа к сети для скачивания Minecraft/Loom). Первая сборка —
> это и есть первая проверка. Если сборка упадёт, пришлите текст ошибки — поправим.

## Что нужно для сборки

- JDK 25
- Gradle 9.6.0 (или IntelliJ IDEA — она сама подтянет Gradle)

## Сборка

Вариант A — локально (с установленным Gradle 9.6.0 и JDK 25):

```
gradle build
```

Готовый мод: `build/libs/liquid-glass-1.0.0.jar` (файл `-sources.jar` не нужен).

Вариант B — через IntelliJ IDEA: откройте папку проекта как Gradle-проект,
укажите JDK 25, запустите задачу `build`.

Вариант C — без установки чего-либо: загрузите папку в репозиторий на GitHub. Workflow
`.github/workflows/build.yml` соберёт jar сам, его можно скачать во вкладке Actions → Artifacts.

## Установка

1. Установите Fabric Loader для Minecraft 26.3 (через установщик на fabricmc.net или лаунчер).
2. Положите `liquid-glass-1.0.0.jar` в папку `mods`.
3. Запустите игру — главное меню будет стеклянным.

## Если сборка ругается на версии

Версии взяты из блога Fabric для 26.3 (Loader 0.19.5, Loom 1.17, Gradle 9.6.0, JDK 25).
Одна из сторонних статей называет более новые: Loom `1.18-SNAPSHOT` и Gradle 9.7.1
(именно `9.7.1`, архива `9.7` не существует). Если Loom 1.17 не подходит, поменяйте версию
в `build.gradle` (plugins) и `gradle-version` в workflow.

## Настройки внешнего вида

- Цвета фона: `Glass.aurora(...)` в `render/Glass.java`.
- Прозрачность и блики стекла: `Glass.panel(...)`.
- Размер и расположение меню: `GlassTitleScreen.init()`.
- Заголовок: константа `TITLE` в `GlassTitleScreen` (в блочном шрифте доступны буквы L I Q U D G A S —
  для других букв добавьте шаблоны в `BlockFont`).

## Структура

```
src/main/java/dev/liquidglass/
  LiquidGlassClient.java      точка входа
  mixin/MinecraftMixin.java   подмена TitleScreen на GlassTitleScreen
  mixin/LivingEntityMixin.java прыжок и взмах руки (только локальный игрок)
  mixin/LevelMixin.java       вид погоды на клиенте
  effects/JumpCircles.java    кольцо частиц
  config/GlassConfig.java     настройки
  screen/GlassScreenBase.java общий вид стеклянных экранов
  screen/GlassTitleScreen.java главное меню
  screen/GlassSettingsScreen.java экран Visuals
  widget/GlassButton.java     стеклянная кнопка
  render/Glass.java           рисование стекла, фон
  render/BlockFont.java       блочный шрифт заголовка
```
